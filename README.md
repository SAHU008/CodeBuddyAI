# CodeBuddy AI 💻

A beginner-friendly Python syntax checker built using Python and Streamlit.

## Features
- Check Python code for syntax errors
- Display the error message and line number
- Provide beginner-friendly explanations
- Offer quick tips for common Python mistakes
- Simple, user-friendly interface

## Technologies Used
- Python
- Streamlit
- Python AST module

## How to Run

1. Install Python.
2. Install Streamlit:

   `python -m pip install streamlit`

3. Run the application:

   `python -m streamlit run app.py`

## Project Goal

To help beginners understand common Python syntax errors and improve their programming skills.
